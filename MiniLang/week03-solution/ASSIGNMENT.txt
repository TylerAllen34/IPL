YOUR C++ TASK
File: src/lexer.cpp
Function: Lexer::identifier(), the body marked TODO WEEK03.
Replace the placeholder comment and throw; keep the surrounding project.

1. Read scanToken() first. It has already consumed the first ASCII letter or
   underscore. start_ marks that character; current_ is the first unread one.
2. Inspect continuation characters with peek(). Accept ASCII letters, digits
   and underscores through the supplied isAsciiAlphaNumeric helper.
3. Consume accepted continuations with advance(). Leave the first nonmatching
   character unread, and do not advance beyond the end of the source.
4. Obtain the whole text from contents_: start start_, length current_ - start_.
   Include the first character that scanToken() already consumed.
5. Classify that complete text with identifierKind(); call addToken() once.
   The helper stores the lexeme and source span.

The result is the appended token and cursor state, not a return value.
[start_, current_) must cover exactly the consumed name. peek() supplies a
nonmatching sentinel at EOF; Lexer::run() adds the EOF token itself.
Do not add a keyword table, parser rule, AST node or runtime operation.
